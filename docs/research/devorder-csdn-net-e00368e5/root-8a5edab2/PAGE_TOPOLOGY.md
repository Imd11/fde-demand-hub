# Page topology

1. Sticky header
   - Brand mark, product name, and a small “前端预览” status badge.
   - Static layout; the header remains visible while the form scrolls on small screens.
2. Primary working surface
   - Left column: concise purpose statement, three-step process, and a backend handoff note.
   - Right column: the requirement intake form, visible immediately in the first viewport on desktop.
   - Desktop uses a 5/7 split; mobile stacks the form after the intro.
3. Form completion state
   - Replaces the form body after a valid submit.
   - Shows a locally generated request number, explains that the demo is browser-local, and offers a new submission action.
4. Footer
   - Minimal privacy and ownership line.

There are no fixed overlays, carousels, hidden navigation, imagery, or scroll-driven interactions.
